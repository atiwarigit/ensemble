# Time-saved baseline

Phase 1's success measure is time saved on routine admin. This template records how long each task
takes **before** Ensemble, so the same tasks can be timed again after a month of use. Fill in the
"before" column now, from a typical recent week, then the "after" column at the 30-day review.

How to measure: time the task the next time you do it, or estimate from the last three times. Count
only hands-on time, not waiting for someone else.
